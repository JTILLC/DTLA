# The Flash program, screen by screen

What `IshidaVR.exe` actually contains and does, found by reading its script
(`tools/swf_structure.py`) and then pressing everything in it under Ruffle
(`tools/original/`) with **power on** and at **Maintenance level (password
1 2 3)** — most of what is below is invisible without both. Every state named
here is in `src/data/navmap.json` as a screen of its own (`parent@state`),
generated by `tools/build_states.py` from the movie's button geometry and the
captures in `public/captured/`.

Coordinates are movie coordinates (800×600), `x,y`.

## How the program is built

- **60 labelled frames** are the screens. Everything else is a *sprite*
  shown, hidden or turned to a page by script.
- **`Panel01`–`Panel10`** on each frame are its pop-ups: numeric keypads,
  the QWERTY keyboard, Yes/No confirms, drop-down lists, the photo picker.
  A key opens one with `PanelNN._visible = true` and calls `BTNon(false)`,
  which **disables and dims every other key on the screen** — that is why
  the whole screen goes pale behind a keypad. `Panel10` is the "Please wait
  a moment." pop-up and sits on 59 of the 60 frames.
- **`_global`** holds the machine's state: `Power` (0/1/2), `KRlevel` (1–4),
  `MenuOpenSW` (the Machine Set drawer, which is one sprite shared by all
  frames and keeps its open/closed state as you move between screens),
  `BTNblinkFLG` (the **?** key), the lamps.
- The frame-2 script shows `Conp01` when `KRlevel == 4`: at Maintenance the
  Main Menu gains the **Preset** key (706,194) and the **Machine Set**
  handle. Below Maintenance neither exists — the Preset key is placed on the
  frame but invisible and dead.
- The **?** key (764,1) toggles `BTNblinkFLG`: every pressable key blinks
  until it is pressed again. The machine's own "what can I press".
- The RCU clock is stamped once at load and never ticks.

## Power

Power OFF is instant, from any screen, and stops production. Power ON shows
"Please wait a moment." with an hourglass and a progress bar for about ten
seconds with the whole bottom bar dead; the four frames in
`public/keys/power-wait-*.png` are that pop-up. With power on, Start goes
green on the Main Menu and Select Preset. Drain START, Full Open's Open,
Test Drive's Drive Start and the wizard's final START are also dead cold.

## Access level

Key icon (544,2) → list: Operator, Site Engineer, Installation, Maintenance.
Operator is immediate; the others open the **Password Input** keyboard.
Empty Enter is rejected. 1 2 3 unlocks Maintenance: four yellow dots, the
Preset key and the Machine Set handle on the Main Menu. Control Panel >
Password Set / LangSlct Set shows the same three levels for setting
passwords.

## Main Menu

Rows of the info box open editors: Product Name and Product Code open the
**keyboard** (CAPS lamp, SHIFT, BS, CLR, CANCEL, Enter); Target Weight,
Speed, Dump Count and Upper Weight Limit open the **keypad** with a
Maximum/Minimum panel beside it (Target Weight 0–99999). The photo box
(700,44) opens Select Preset. The **Select Total** strip on the left edge
opens the six total views.

## Select Preset

HOME is dimmed: **Exit is the only way out, and it is also what commits the
card you picked.** Preset No. (697,66) opens a keypad (max 200, min 1).
Slct Dsply switches card and list views. The grid scrolls — there are more
than ten presets.

## Preset editor (Maintenance only)

Tabs Product / Machine / Item / Others across the bottom; Finish Prdct
Setting / Feeder Adjustment / Timing Adjustment / Weight Setting down the
right. HOME dimmed; Exit leaves. Cancel lights once something changes.

- **Product**: Product Name and Code (keyboards), Product Category
  (keyboard), Preset No. (keypad), the photo box (a picker of four
  pictures), **Camera** ("Do you want to take photo of product?").
- **Machine**: Speed, Dump Count, Interlock Parameter Number (drop-down),
  Section Parameter Number, **Average Control Off/On** — On makes the
  Weight page show **Lower Weight Limit** (4.5 g here); Off hides it.
- **Item**: Auto Feed Target, Feed Multiplier, Disch. Priority Count,
  Hopper Action Parameter Number, Good Efficiency Judgement Value, Photo
  SW Off/On, Shutter Drive Off/On. (No scrolling despite the bar.)
- **Others**: Stable Time (400 msec).
- **Feeder Adjustment**: a *bar-chart* feeder view (RF bars for 14 heads,
  DF bar), Time/AMP lamp keys, ▲▼, **Read Default** ("Set default value of
  RF and DF. OK?"), Read OptimumVal, a Feeder tab.
  The **(1) under the DF bar** picks the dispersion feeder (seen 2026-09-03):
  it turns blue, a **Target Wt** key appears above Read OptimumVal reading
  500, and ▲▼ move the DF values (both lamps were lit: 25.0/50.0 → 26.0/51.0).
  Target Wt opens a "DF Weight Setting" keypad — 500, Maximum 9999, Minimum
  1, digits append. Enter there opens **Upper Limit(%) Setting** (20, Maximum
  100, Minimum 0), Enter again **Lower Limit(%) Setting** (20, same limits),
  and Enter again returns; CANCEL on any step drops straight back.
  Pressing the (1) again clears it (readout blanks to ".0");
  pressing a head number clears it and picks that head alone.
- **Timing Adjustment**: the timing table (WH-DS 110, IS-WH 0, WH-PH 200,
  PH-RF 150, STAGGER 0, WH ON 450, PH ON 400), row select highlights the
  hoppers on the 3-D cutaway (weigh hoppers for WH-DS / IS-WH / WH ON, pool
  hoppers for PH-RF / PH ON, the DS/IS tags and blue arrow following; the
  header keeps saying WH-DS), Auto Cal Off (did not respond here), **Entr**
  keypad ("Time Input",
  max 2550, min 1, digits append to the shown value), ◀◀ −100, ◀ −10,
  ▶ +10, ▶▶ +100 ms.
- **Weight Setting**: Extended Upper Limit, Extended Upper Limit Dump
  Cycle, Upper Weight Limit, Target Weight, Lower Weight Limit (see Average
  Control), each a keypad, with the green/yellow/red band drawn beside them.

## Zero Adjustment

Opens with every hopper selected (blue). Tap a hopper to deselect; Slct All
DF selects only the pan, Slct All WH all hoppers. **Start** shows "Please
wait a moment." with the progress bar over the hoppers, Start lit green;
when it clears the selection has gone.

## Drain

Tabs Weight Display / Feeder Adjust / Timing Adjust. **Auto Zero** and
**Infeed Control** are lamp keys (they work unpowered). **Drain START**
(power on) runs the drain: it greys, Drain STOP lights, HOME greys; Exit
still works. Drain STOP ends it.

## Full Open Lock

Unit Select: DF, RF, PH, WH lamp keys — each lit unit is painted blue on
the machine picture. **Open** (power on) opens and **locks the screen**:
HOME and Exit grey until **Close**. Feeder Adjust tab: the same feeder
screen as Production.

## Production (Start from the Main Menu or Select Preset; power on)

Live weight counts at the top. Tabs Combination / Feeder Adjust / Timing
Adjust / Total Data / Weight Display. **HOME and Exit are dimmed while
running; Stop lights them and Start.** Power off mid-run stops and cuts
power in one press. **Write feeder OptimumVal** asks "Set the current RF
and DF value as optimized value. OK?". **Infeed Control** is a lamp key.

- **Combination**: hopper ring with the selected heads, the preset box, the
  Select Display strip with two views (the ring; a full-screen weight).
- **Feeder Adjust**: see `ccwr-simulator-fidelity` for the counted rules.
  The ① on the centre disc selects the **dispersion feeder**: the disc
  turns blue, the RF arrow reads DF, and the chart draws one circle per
  parameter. The blue → ← arrows do nothing. Head mean and Section mean are
  lamp keys. **Live** replaces the trough graphic with the camera picture of
  product on the dispersion feeder; **C.G.** brings the graphic back. The
  **Feeder** tab (729,395) slides out a drawer of four chart modes:
  operating status ("Under AFD control" with Good condition / Too many
  unavailable heads / Unstable product flow lamps), the radar chart, a
  two-row bar chart with ▲▼ keys, and **AFD Setting** (a range table and
  eight control-mode radios: Manual, Efficiency Ref., Auto Single, Auto
  Time Single, Auto AMP Single, Auto Multi, Auto Time Multi, Auto AMP
  Multi). Switching chart views clears the head selection.
- **Timing Adjust**: as in the preset editor, with the Entr keypad.
- **Total Data**: efficiency bar, histogram; Total Log and Output keys do
  nothing visible; the **Select Total** strip on the left edge opens the
  six total views.
- **Weight Display**: per-head weights on the ring, infeed weight on the
  disc.

## Machine Set drawer (Maintenance)

Handle at (168,495) on 40 frames — one shared sprite, so it stays open or
closed as you move. Seven items: Manual Adjustment, Auto Adjustment,
Self-diagnosis, Display&Data Manager, Various Parameter Setting, Weigher
Setting, Peripheral Equipment Setting. The title bar closes it.

- **Manual Adjustment**: tabs Weighing Adjst / Combi. Calcltn / AFV Monitor
  / WeighData Disp. **All Head SLCT/CLR** selects every hopper and enables
  **Zero Adjst** (the wait pop-up) and **WH Span Adjustment**, which on this
  demo plays a **SPAN ERROR** (hoppers red; "Ch1 WH1…14"; Power / Err
  Clr&Stop / Description). Err Clr&Stop does nothing; Description shows
  "Span weight is not 200g…"; only a reboot gets out. WeighData Disp has
  DF/RF/PH/WH lamps, Filter Output radios and Drive Stop/Start.
- **Self-diagnosis**: Device Check, In/Output Signal, Network Analyze,
  Program Number, Test Drive (Drive Start greys the unit keys and lights
  Drive Stop).
- **Display&Data Manager**: Layout Setting (Head No 1 location), Preset
  Manager (opens on a "Loading preset data" pop-up, ~4 s; the arrow key by
  each Memory field opens a Memory / Card list - a pick closes it without
  changing the field; a tap on a row on each side picks copy source and
  copy destination, the Copy key then shows both numbers and asks
  "Performs copying of preset contents from copy source to copy
  destination." - Yes writes it (1 -> 4 seen); All Select did nothing;
  Initialize asks "Initialize the Memory. OK?"), Machine Set Mngr, All
  Setting Mngr (Memory / EEPROM / Card Initialize), Hopper Name Set (three
  drop-downs).
- **Various Parameter Setting**: Weigh Spec Set (Range, Stable Judgment
  Weight, Empty Judgment Weight keypad, Auto Zero…), Combination Set,
  Sectioning Set, FD Spec Set, **H DRV Spec Set** — a list of Pool Hopper /
  Weigh Hopper / Booster Hopper / RingShutter / DivertingTimingHppr /
  TimingHopper, each its own page of drive parameters (Actuator Type,
  Brake Time, Phase Type, pulse counts…). The ▼Parameter1 header did not
  respond under Ruffle; on the real program it shows further parameters.
- **Weigher Setting**: Active head, Auto timing set, Network setting, AFD
  Setting (AFD Stop for Fewer Available Head, Cleaning Request, DF Adjust
  for Overfeed, DF WT Adjustment radios).
- **Peripheral Equipment Setting**: Pckr Intrlck Set (Dump Confirm Hold
  keypad, Interface, Multi D…), Infeedr Cntl Set; the right-hand list
  (Pckr Intrlck Set / RingShutter / DivertingTimingH… / TimingHopper) is
  the other pages.

## Control Panel (monitor icon)

Screen Control (Backlight Saver, BL Saver On Time ▲▼, Touch Panel
**Tune-up** → "Screen moves to calibration screen…" → Yes shows a
calibration cross top-right, then bottom-left), Password Set / LangSlct
Set, Destination ID (Printer; Brwsr Set; E-mail Setting), Com. Setting
(RCU IP, gateway, mask, MAC; Main Body DACS).

## Start-Up Assistant (signpost icon)

The icon goes green while it runs. Next → Select Preset with an overlay
panel and a magenta **OK** → **WH Zero Adjustment Start** (a step diagram
down the left, Start/Next, instructions) → In WH Zero Adjst. (progress bar,
advances itself) → DF Zero Adjustment Start → In DF Zero Adjst → Production
Standby ("Zero adjustment is now complete, press START") → Production.

## Message Board (document icon)

Brush, thin and thick pencils, red/blue/black paint, eraser, trash;
dragging on the board draws. **Transmit** → "E-mail will be sent. OK?".
Trash → "Delete OK?". The bottom bar is entirely dead here.
